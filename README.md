# Mana AI – Local AI Assistant

Mana AI is a lightweight AI-powered web application built using Flask and Ollama. The application allows users to interact with a locally hosted Large Language Model (DeepSeek-R1:8B) through a simple and intuitive web interface. Unlike cloud-based AI tools, Mana AI runs entirely on the user's machine, ensuring privacy, reduced dependency on external services, and zero API usage costs.

The application provides multiple text-processing features, including:

* Explain a Concept – Generates clear and easy-to-understand explanations.
* Summarize Text – Produces concise summaries of lengthy content.
* Rewrite Professionally – Rewrites text in a polished and professional tone.
* Convert to Bullet Points – Organizes information into structured bullet points.
* Translate Text – Translates text into English.

The backend is developed using Python and Flask, while the frontend uses HTML, CSS, and JavaScript to deliver a responsive and user-friendly experience. The application communicates with a locally running DeepSeek-R1:8B model through the Ollama API, enabling fast and secure AI inference without requiring external API keys.

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* Ollama
* DeepSeek-R1:8B
* OpenAI Python SDK (used for local Ollama API compatibility)

## Key Features

* Fully local AI processing
* No paid API requirements
* Clean and minimal user interface
* Multiple text transformation tools
* Real-time AI-generated responses
* Privacy-focused architecture

Mana AI demonstrates how modern Large Language Models can be integrated into web applications while maintaining simplicity, affordability, and user data privacy.
